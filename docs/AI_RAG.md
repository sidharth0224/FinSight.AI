# Hybrid SQL and document intelligence

Questions are classified into budget comparisons, expense investigations, policy questions, financial analytics, audit summaries, hybrid questions or unsupported requests. Routing is deterministic. Server-owned finance methods validate the authenticated scope; no arbitrary model-generated SQL is executed. Numerical evidence is computed before language generation. Supported comparisons derive absolute and percentage differences with Decimal arithmetic.

NVIDIA configuration is server-only: `NVIDIA_API_KEY`, `NVIDIA_BASE_URL`, `NVIDIA_CHAT_MODEL`, `NVIDIA_EMBEDDING_MODEL`, and `NVIDIA_EMBEDDING_DIMENSIONS`. A model's presence in `/models` does not guarantee account access; test a small request. The service imposes timeouts, three bounded attempts for transient errors, rate-limit handling, zero temperature and a bounded output token budget. No local model runs on EC2.

The brief's default `nvidia/nv-embedqa-e5-v5` is preserved in the configuration template. During live verification on October 10, 2026, that hosted endpoint returned HTTP 410. The supplied account successfully returned 1024-dimensional vectors from `nvidia/llama-nemotron-embed-vl-1b-v2` using `dimensions:1024`. The local server configuration explicitly selects that alternative. Chat access was verified with `nvidia/nemotron-3-super-120b-a12b`. Do not silently substitute providers or reuse vectors generated by another model. NVIDIA documents configurable embeddings in its [embedding reference](https://docs.nvidia.com/nim/nemo-retriever/embedding/2.0/reference.html).

Text-based PDF, DOCX and TXT policies are validated, stored privately and extracted. PDF ingestion retains actual parsed page indexes; TXT and DOCX citations omit page numbers. Scanned PDFs produce a readable processing error. Approximate 350–500 token chunks use word boundaries and modest overlap; batches contain eight passages. The embedding service uses `input_type:passage` for indexing and `input_type:query` for retrieval, checks every dimension and rejects invalid or nonfinite vectors.

Retrieval obtains authorized document IDs first, rejects mismatched indexing metadata, then performs a parameterized cosine search. The relevance threshold is 0.65. If no matching evidence is retrieved, the Copilot reports insufficient evidence. Original files use short-lived signed download URLs after a fresh authorization check.

The model receives only authorized source passages and verified finance results. Source content is explicitly untrusted and cannot override system instructions. Answers cite `[source:ID]`. Referenced IDs are validated against the supplied evidence. Missing or unknown citations prevent a verified label. Sources, metrics, tables, charts and follow-ups are returned as structured JSON; chart code is never executed from the model. NVIDIA failures return available structured evidence with a visible explanation-service warning.

The first implementation waits for a complete grounded answer and supports cancelling the browser request. It does not stream tokens; cancellation does not necessarily stop an in-flight hosted provider request. Multi-conversation storage, deletion, Markdown, tables, charts, copy and evidence inspection are implemented.
